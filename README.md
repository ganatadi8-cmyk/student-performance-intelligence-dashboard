# Student Performance Intelligence Dashboard

An ML-powered Streamlit project for predicting student academic performance.

## Features
- Final score prediction
- Academic risk classification
- Personalized improvement suggestions
- Feature-importance chart
- What-if improvement simulator

## Tech Stack
- Python
- Streamlit
- pandas
- NumPy
- scikit-learn

## Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy
For Streamlit Community Cloud, set the main file path to:
`app.py`

## Resume Line
Built an ML-powered Student Performance Intelligence Dashboard using Python, scikit-learn, and Streamlit to predict academic outcomes, classify risk, explain feature importance, generate personalized recommendations, and simulate improvement scenarios.

## Note
The dataset is synthetic and the application is for learning/demo purposes only.
